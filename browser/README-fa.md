# اتوماسیون مرورگر + Gemini Pro

کنترل **Chrome شخصی روی کامپیوتر خودت** از طریق CDP — بدون نیاز به دانلود مرورگر جدید و بدون دست‌زدن به کروم اصلی.

## راهاندازی (فقط یک بار)

```powershell
cd "E:\New folder (2)\browser"
node gemini.mjs open
```

پنجرهٔ جدیدی از Chrome با پروفایل مجزا (AutomationChrome / Jolfaa) باز میشود.
**یک بار** با حساب Gemini Pro خودت لاگین کن — سشن ذخیره میشود و دیگر لازم نیست.

> **نکته:** کوکیهای کروم مدرن با رمزنگاری متصلبهنصب (app-bound) ذخیره میشوند، پس کپی
> کوکی از پروفایل اصلی کار نمیکند — لاگین دستی یکبار در همین پنجره ضروری است.
> بررسی وضعیت لاگین: `node check-gemini.mjs`

## استفادهٔ روزمره

```powershell
node gemini.mjs ask "یک لندینگپیج فارسی برای Trend Cargo طرح بزن"
node gemini.mjs screenshot out.png
```

- پاسخ در `gemini-outputs/last-response.md` ذخیره میشود
- اسکرینشات آخرین وضعیت در `gemini-outputs/last.png`

## نحوهٔ کار فنی

- `chrome-control.mjs` — اگر Chrome با پورت دیباگ `9222` در حال اجرا نباشد، آن را با پروفایل مجزا بالا میآورد و با playwright-core متصل میشود.
- `gemini.mjs` — به gemini.google.com میرود، پرامپت را تایپ میکند، منتظر میماند پاسخ کامل شود (تثبیت متن ۲.۵ ثانیهای)، و ذخیره میکند.

## عیبیابی

- **«جعبهٔ پرامپت پیدا نشد»**: احتمالاً لاگین نیستی → `node gemini.mjs open` و لاگین دستی.
- **DOM گوگل عوض شده**: اسکرینشات بگیر (`screenshot`) و سلیکتورهای `findPromptBox`/`readLatest` را با کمک ایجنت آپدیت کن.
- **پورت ۹۲۲۲ اشغال است**: Chrome دیگری با همان پورت بالا است → آن را ببند.
