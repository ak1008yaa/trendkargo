# رفرنس دیزاین: MotionSites AI

> منبع: https://motionsites.ai (رفرنس رسمی دیزاین پروژه — کاربر اعلام کردهاند)
> تاریخ: ۲۰۲۶-۰۹-۱۷

## این سایت چیست؟
**MotionSites AI** یک کتابخانهٔ پرامپت و آکادمی آموزش «دیزاین وبسایت با AI» است. محصول اصلی آن پکیجهای آمادهٔ پرامپت برای ساخت لندینگپیجهای انیمیشنی است. این سایت **استاندارد دیزاین مرجع** پروژه است و باید در تمام کارهای UI، موشن و لندینگپیج آینده دنبال شود.

## ساختار صفحه (مقطعها)
1. **Hero**: شعار بزرگ و متمایز — «Unlock your AI Design Superpowers» با تایپوگرافی تبلیغاتی درشت و CTA واضح.
2. **مقایسه/تازهها**: بخش «Fresh Drops Everyday» برای محتوای روزانه.
3. **تمهای آماده (Apps/Sections)**: گالری بزرگ از پرامپتها بر پایهٔ بخشها:
   - Hero Section (مثل EMPER.dsgn, Digital Epoch, RIVR DeFi Landing Page)
   - Footer Section (Vize, Kresna, Lumina, Zenith)
   - Features Section (Glow)
   - Pricing Section
   - CTA Section (Community, Slam Dunk)
   - نمونههای صنعتی: NOVA Space Systems (فضایی)، AKOR Security (سکیوریتی)، Finlytic AI Agent SaaS، Nexus IT Solutions، Bionova Biotech SaaS
4. **دستهبندی انیمیشنی «Animated Backgrounds»**: پسزمینههای متحرک برای تبدیل و جلب توجه.
5. **آکادمی/یادگیری**: بخش «Master AI-powered Design» برای آموزش.
6. **Pricing**: «What Package Fits You» — سهپایهٔ قیمت.
7. **CTA پایانی**: ایمیلکچر با وعدهٔ ارزش («Give Me Just a Few Days…»).

## زبان بصری و هویت
- **برندینگ**: لاگوی «M» با گرادیان صورتی-نارنجی-بنفش؛ هالهٔ نورانی؛ نویز/گلاش.
- **حالت**: تیره (dark-first)، مناسب پسزمینههای گرافیکی.
- **تایپوگرافی**: عنوانهای درشت، ضخیم، متضاد؛ بدنهٔ ساده و خوانا؛ حس «انسانی + تکنیکی».
- **موشن**: حرکت روان، hover، انیمیشنهای پسزمینه (اسکرولترگر)، transitions سریع.

## قواعد پیادهسازی در پروژههای ما
1. **Hero اول** — شعار بزرگ + یک CTA اصلی + المان انیمیشنی (canva/canvas/WebGL یا CSS).
2. **گالری نمونهها بهصورت کارت**: هر کارت = اسکرینشات + تگ (Hero/Pricing/Footer) + دکمه.
3. **بخشبندی واضح**: حداقل ۶ مقطع (Hero، گالری، بکگراندها، آکادمی، Pricing، CTA).
4. **پشتیبان فارسی/RTL**: اگر سایت فارسی است، همجهت با این ساختار اما mirror شده (استایل grid داخلی RTL).
5. **انیمیشن**: ورود تدریجی (staggered reveals)، اسکرولترگر، hover پیشرفته؛ ترجیحاً CSS-only یا three.js در بکگراند.
