# ترندز کارگو | Trend Cargo

فروشگاه استاتیک (HTML/CSS/JS خالص) برای کسب‌وکار کارگو و خرید مستقیم از تمو، شین و آمازون.
بدون فریمورک، بدون مرحله build و بدون نصب پکیج — مستقیماً روی هر هاست استاتیک یا Vercel قابل انتشار است.

---

## اجرای محلی

```bash
python -m http.server 8000      # یا هر سرور استاتیک دیگر
```

سپس در مرورگر: `http://localhost:8000`

## بسته‌بندی برای انتشار

```bash
python pack_project.py          # خروجی: trendcargo-final.zip (فقط فایل‌های استاتیک)
```

## مدیریت تصاویر (مهم)

تمام تصاویر سایت **به‌صورت محلی در `assets/img/` نگهداری می‌شوند** و از خود هاست/Vercel سرو می‌شوند.
هیچ تصویری از دامنه‌های بیرونی (مثل Unsplash) به‌صورت hotlink بارگذاری نمی‌شود؛ بنابراین:

* سرعت بارگذاری بالاتر و پایداری بیشتر (بدون وابستگی به سرویس بیرونی)
* CSP سخت‌گیرانه‌تر (`img-src 'self' data:`)
* کش طولانی‌مدت روی `assets/` توسط `vercel.json`

اگر بعداً تصویری از منبع بیرونی اضافه کردید، با یک دستور همه را دانلود و مسیرها را اصلاح کنید:

```bash
node tools/localize-images.cjs --dry-run   # فقط گزارش، بدون تغییر
node tools/localize-images.cjs             # دانلود + بازنویسی مسیرها
```

این ابزار همچنین هر تصویر «مفقود» یا «حذف‌شده در منبع» را به `assets/img/placeholder.svg` هدایت می‌کند
تا هیچ‌وقت آیکون شکسته در سایت نمایش داده نشود.

## نکات توسعه

* **حالت/داده**: تمام state روی `localStorage` است. کلیدها و ساختار داده‌ها را تغییر ندهید (فهرست کلیدها در `js/script.js` بخش `STORAGE_KEYS`).
* **اسکیمای محصول**: `id, category, catName, title, price, rawPrice, tag, mainImg, gallery, desc, specs`
* **تم**: هم `data-theme` روی `<html>` و هم منطق toggle در JS را با هم به‌روز کنید.
* **سرویس‌ورکر**: هنگام تغییر فایل‌های استاتیک، مقدار `CACHE_VERSION` در `sw.js` را افزایش دهید.
* **زبان**: تمام برچسب‌های کاربری فارسی و چیدمان RTL است؛ این الگو را حفظ کنید.

## انتشار روی Vercel

کانفیگ موردنیاز در `vercel.json` است (هدرهای امنیتی، CSP، کش دارایی‌ها و `cleanUrls`).
پروژه به‌صورت کاملاً استاتیک منتشر می‌شود؛ `backend/` روی Vercel اجرا نمی‌شود و برای آن باید یک سرویس جداگانه (Render / Railway / VPS) در نظر بگیرید.
