# پکیج اسکیل‌های حرفه‌ای (Professional Skills)

این پوشه شامل **۵ اسکیل حرفه‌ای** است که برای ارتقای ایجنت هوش مصنوعی (Cline) ساخته شده‌اند.
هر اسکیل یک فایل `.skill` (فرمت زیپ استاندارد) است که می‌توان آن را مستقیم در پوشه اسکیل‌های‌ ایجنت نصب کرد.

## لیست اسکیل‌ها

| اسکیل | حوزه | کاربرد اصلی |
|-------|------|-------------|
| `code-engineering` | برنامه‌نویسی | کد تمیز، معماری نرم‌افزار، الگوهای طراحی، رفاکتورینگ، بازبینی کد، تست‌نویسی، بهینه‌سازی عملکرد |
| `design-engineering` | دیزاین | سیستم دیزاین، تایپوگرافی، رنگ، چیدمان، پشتیبانی کامل RTL و فارسی، دسترس‌پذیری WCAG، ریسپانسیو |
| `appsec-engineering` | امنیت | تهدید مدلینگ (STRIDE)، OWASP Top 10، کدنویسی امن، مدیریت اسرار، هدرهای امنیتی و CSP |
| `ai-engineering` | هوش مصنوعی | ساخت برنامه‌های مبتنی بر LLM، RAG، پرامپت نویسی، انتخاب مدل، گاردریل‌ها، ارزیابی (Evals) |
| `agent-builder` | ساخت ایجنت | معماری ایجنت، طراحی ابزارها، Function Calling، سرورهای MCP، حافظه، ارکستراسیون چندایجنتی، ایمنی |

## نصب

**روش ۱ — نصب مستقیم (در همین سیستم):**
فایل‌های `SKILL.md` هر اسکیل در پوشه زیر قرار گرفته‌اند و همین حالا فعال هستند:
```
C:\Users\home\.agents\skills\<نام-اسکیل>\SKILL.md
```
پس از ری‌استارت یا بارگذاری دوباره سشن ایجنت، اسکیل‌ها در دسترس خواهند بود.

**روش ۲ — نصب به‌صورت پکیج (روی هر سیستم/ایجنت دیگری):**
۱. فایل `.skill` موردنظر را از این پوشه بردارید.
۲. در محیط ایجنت مقصد، آن را آنزیپ کرده و محتوای پوشه را در پوشه اسکیل‌ها کپی کنید.
۳. برای نصب، کافی است پوشه اسکیل (که حاوی `SKILL.md` است) در محل اسکیل‌های ایجنت قرار بگیرد.

## اعتبارسنجی

همه اسکیل‌ها با اسکریپت اعتبارسنجی رسمی (معادل `quick_validate.py`) بررسی شده و وضعیت `PASS` گرفته‌اند:
```powershell
node tools/validate-skills.cjs C:\Users\home\.agents\skills\code-engineering ...
```

## نکته مهم

- توضیحات هر اسکیل شامل کلمات کلیدی فارسی هم هست؛ یعنی اگر به فارسی از ایجنت بخواهید «کد را امن کن»، «رابط کاربری طراحی کن» یا «ایجنتی بساز»، اسکیل مربوطه خودکار فعال می‌شود.
- همه اسکیل‌ها اخلاقی و دفاعی طراحی شده‌اند؛ مثلاً اسکیل امنیت، بدون مجوز صریح، عملیات تهاجمی انجام نمی‌دهد.

## حالت اجرای سریع ایجنت‌ها

برای جلوگیری از برنامه‌ریزی طولانی، همهٔ ایجنت‌های پروژه از پروتکل
`agents/EXECUTION-PROTOCOL.md` استفاده می‌کنند. این پروتکل انتخاب ایجنت را کمینه،
سؤال‌های غیرضروری را حذف، بودجهٔ جست‌وجو را محدود و اعتبارسنجی هدفمند را اجباری می‌کند.
اسکیل‌های حوزه‌ای همچنان مسئول تخصص خود هستند؛ پروتکل فقط ترتیب اجرا و قالب تحویل را کوتاه می‌کند.
